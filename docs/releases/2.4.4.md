# HomeConnect 2.4.4

A speed fix for the dashboard. No migrations, no phone app change.

## Fixed

- **The dashboard took several seconds to show its figures**, most of all with every branch selected. The time was spent in the backend's own calculations, not in the database:
  - Every conversion of a timestamp to a shop date built a new date formatter. One formatter per timezone is now reused, which also speeds up reports and other date-heavy screens.
  - The top debtors list searched every open debt again for each customer; it is now built in one pass.
  - When the page opens and a refresh fires at the same moment, both requests now share one calculation instead of running it twice.
- Measured on a restored copy of a shop backup with every branch selected: loading all dashboard cards together went from about 6.6 seconds to about 1 second on the development laptop. A slower shop PC will take longer, but in the same proportion.

## Not changed

- Figures, totals and per-branch breakdowns are calculated exactly as before.
- Database indexes were already in place for every link the dashboard reads, so none were added.

## Operator checklist

1. Install desktop **2.4.4**.
2. Open the dashboard with all branches selected and check that the cards appear within a couple of seconds.

## Verification

- Dashboard, report and business-date tests pass (223 tests), including a new test for shared in-flight requests.
- Not verified: timing on the shop PC itself.
