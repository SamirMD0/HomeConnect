# HomeConnect 2.4.9

The customer import now shows the old system's balance next to HomeConnect's, so a credit held as a deposit no longer looks like a difference. No PC database migrations, no phone app change, no relay change.

## Fixed

- **The import looked 200 $ off after a correct import.** A customer credit in the trial balance is kept in HomeConnect as a deposit. "Owed after import" counts debts only, while the old system's total subtracts credits, so the two never matched while any credit existed. The import now compares the same figure on both sides.

## Changed

- **Total balance at the top of Preview and Resolve.** Old system balance (debts minus credits in the file), HomeConnect after import (what customers owe minus deposits held), and the difference. Green "Matches" when they agree; amber with the amount and the branch when they don't.
- **The total follows your choices on Resolve.** Skipping a row or keeping HomeConnect's figure shows the difference it leaves straight away.
- **Totals by branch** adds "Old system balance" and "Balance after import" for each branch and the total.
- The "already imported" note now says only rows that already agree default to Skip.

## Operator checklist

1. Install desktop **2.4.9**.
2. Import the trial balance into IMPORT as usual.
3. Check the box at the top of Preview shows **Matches**. If it shows an amount, the branch with the difference is named under it.
4. On Resolve, leave rows on Update unless you mean to keep HomeConnect's figure; the box shows what each skip leaves.
