# HomeConnect 2.4.3

A fix to the customer import from the old system's trial balance. No migrations, no phone app change.

## Fixed

- **Customers who paid off in the old system kept their debt.** The old system's trial balance leaves out accounts at zero, so a customer who paid in full simply disappeared from the file and the import never cleared their HomeConnect balance. The preview now shows a **Not in this file** list: customers an earlier import brought in who still owe in HomeConnect but are not in this trial balance, with what they owe and the last file they appeared in. **Settle to zero** is ticked by default and records a payment (method Other) on commit. Customers with a sale or payment taken in HomeConnect since the last import are left unticked. The main branch is never listed or changed.
- **The same rows came back as Conflict on every import.** When the old system's balance is unchanged since the previous imported file but HomeConnect differs, the row now goes to a new **Old difference** tab instead of Conflict, with no money change by default. Tick **Apply this change** once to bring the customer in line. Real changes in the old system after a payment taken in HomeConnect are still shown in Conflict.
- The Confirm step's branch totals, the result summary and the downloadable import report include the settled customers, so "Owed after import" can be compared with the old system's total.

## Operator checklist

1. Install desktop **2.4.3**.
2. On the next customer import, review **Not in this file** and untick anyone who should keep their balance.
3. In **Old difference**, tick **Apply this change** for the rows that should follow the old system, then continue.
4. On Confirm, compare **Owed after import** for each branch with the old system's total, then commit with the account password.
