# HomeConnect 2.2.0

This release adds everything the **Home Connect phone app (2.0)** needs from the shop PC. The phone is another screen for the same system: it connects over the shop Wi-Fi to this PC (port 3011) and saves straight into the same database.

## New

- **Supplier bills inbox.** Bill photos can be saved for a supplier before the purchase exists, then linked to a purchase later from the phone or the PC.
  - **Bills tab:** the supplier's page on the PC has a **Bills** tab (Unlinked / Linked / All) with a full-size viewer (zoom, rotate, download) and **Link to purchase**.
  - **Attached bills:** receiving details show the bills attached to them.
  - **Badge:** the **Suppliers** menu item shows an amber count when bills are waiting.
- **Phone access to the whole system.** The phone connection now allows every PC feature except the PC-only areas: backup and restore, maintenance, diagnostics, preflight, setup, system and scanner administration. Every request is still checked against the user's role and branch, exactly as on the PC.
- **The phone stays signed in.** The phone connection passes the login renewal to the phone, so staff are no longer signed out every hour. The PC's own sign-in is unchanged.
- **Version handshake.** `GET /api/v1/system/client-compat` tells the phone which PC version it is talking to. Phone apps older than 1.2.0 are asked to update.

## Fixes

- **Receiving saved twice at the same moment.** When the same receiving arrived twice at once (for example a retry on poor Wi-Fi), one of them returned a server error. Both now return the same receiving, and stock is still added only once.
- **Bill photos from the phone.** Photos are compressed on the phone, uploaded reliably, retried when Wi-Fi returns, and never uploaded twice. The upload limit is 8 MB.

## Migration notes

- `20261111120000_supplier_bills_inbox` runs on install, in one transaction. It gives each existing bill photo its supplier and branch (taken from its receiving), makes the receiving optional, adds a note field, and adds the `supplier_receipt_blobs` table (used only in hosted mode).
- **Before installing on the shop PC,** run this check against the shop PC database. It must return **no rows**:

  ```sql
  SELECT r.id FROM supplier_receiving_receipts r
  JOIN supplier_receivings s ON s.id = r."supplierReceivingId"
  WHERE s."supplierId" IS NULL;
  ```

  Any row is a bill photo attached to a receiving with no supplier. The migration then stops without changing anything, and the pre-migration backup is kept. Assign a supplier to those receivings first. On the development laptop the check returned 0 rows and the migration applied cleanly.

## Operator checklist

- Windows Firewall must allow incoming **TCP 3011** on the **Private** network for the phone to connect:

  ```powershell
  New-NetFirewallRule -DisplayName "Home Connect phone (3011)" -Direction Inbound -Protocol TCP -LocalPort 3011 -Profile Private -Action Allow
  ```

- **Phone connection:** in **Scanner Hub**, turn on **Mobile Scanner**, and pair the phone app by scanning the QR code.
- **Bills:** take a bill photo on the phone without a purchase. It appears in the phone's Bills inbox, and the PC's Suppliers badge goes up. Link it to a purchase, and the badge goes down.
- **Bill viewer:** open a supplier's **Bills** tab and open a photo full size.
