# HomeConnect 2.4.10

The dashboard shows deposits held for customers beside outstanding debt, so a customer credit no longer looks like extra debt. No PC database migrations, no phone app change, no relay change.

## Fixed

- **Outstanding debt read higher than the old system by every credit.** Outstanding counts debts only; a deposit held for a customer (a credit in the old system, or a prepaid order awaiting delivery) was shown nowhere. It is now shown next to it, with the net figure the old system uses.

## Changed

- **Outstanding Debt card:** under the amount, "Deposits held · Net" appears whenever any deposit is held.
- **Branches table:** new **Deposits held** and **Net balance** columns per branch and for all branches.
- Outstanding itself is unchanged, so Receivables and reports show the same figures as before.

## Operator checklist

1. Install desktop **2.4.10**.
2. On the dashboard, compare each branch's **Net balance** with the old system's balance for that branch.
3. If a branch shows a deposit the old system does not have, open **Deposits**: a prepaid order whose goods were already handed over should be marked **Delivered**.

## Verification

- Checked in the app on a local copy of a recent shop backup: the card and the Branches table show deposits held and the net, and the net per branch equals the old system once delivered prepaid orders are marked delivered.
- New tests: analytics totals keep deposits out of outstanding and net them in the balance (voided payments ignored); the card line renders, and nothing renders without deposits.
- 293 dashboard and branch database tests and 70 dashboard unit tests pass; backend and frontend typechecks are clean.
