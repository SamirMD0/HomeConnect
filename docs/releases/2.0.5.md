# Home Connect 2.0.5

- Restore reading inventory CSV files with blank cost and total headings; support files containing up to 2,000 products.
- Organize product categories beneath logical families, including Home Appliances, Small Appliances, Electronics, Beauty, Kitchenware, Lighting & Electrical, Tools, and Gaming.
- Automatically assign detected product categories during import. Unidentified products use a family selector followed by categories belonging to that family.
- Add default brands and an All brands import option. Selecting a specific brand assigns it to every imported row.
- Initialize default category families when the backend starts, preserving existing category IDs and product links.
- Improve Electron development startup and prevent chart warnings while containers have no measured size.

Existing products and duplicate imports continue to require conflict review before committing inventory changes.
