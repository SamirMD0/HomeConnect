# HomeConnect 2.0.7

Fix mobile account sign-in on the Scanner Hub LAN port. Scanner-only desktop builds answered the phone's login request with HTTP 404 even though the browser scanner page loaded successfully.

The desktop installer includes the mobile LAN gateway for account login, product lookup, and supplier workflows. These requests use the desktop's existing authentication, permissions, validation, and rate limits. Desktop-only routes remain inaccessible on the LAN listener.

Close HomeConnect on the business PC, install `HomeConnect-Setup-2.0.7.exe`, reopen it, and turn on Mobile Scanner in Scanner Hub. Keep the phone pointed at the IP and port shown there and sign in with the existing HomeConnect username and password. The currently installed phone app can use these routes without reinstalling the APK.

The mobile source also checks the authenticated account route during setup and explains when a PC build lacks mobile sign-in support. That diagnostic improvement requires a new phone build; it is not needed to resolve sign-in with the corrected desktop installer.

This build also includes receipt-photo snapshots alongside database backups and pre-migration backups for the mobile supplier workflow.

## Verification status

The Windows build, focused account/LAN and mobile API tests, mobile typecheck, installer integrity check, and packaged mobile route probe passed. The route probe used a synthetic account service and did not access the business database.
