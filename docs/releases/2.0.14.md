# HomeConnect 2.0.14

A fix for a crash on the customer page.

## Fixes

- Opening a debt or installment plan that has a payment no longer crashes the customer page with "Cannot read properties of undefined (reading 'replace')". The crash came in with 2.0.12's work and affected 2.0.13.

## Changes you will see in debt and installment plan details

- Payment lines now show what each payment was allocated to, and the debt or plan name. If one payment also covers another debt, that line shows "No description".
- Reallocate now appears on installment plan payments for users who can change financial records.
- Void and Reallocate no longer appear on payments that came from a sales order, the same as the customer overview.

## Migration notes

None. This release has no database changes.

## Operator checklist

Beyond the default [upgrade smoke test](upgrade-smoke-test.md):

- Open a customer with a paid or part-paid debt, then open that debt's details. The payment lists without a crash.
- Do the same with an installment plan that has a payment.
- Reallocate a test installment payment from the plan details, since this button is newly reachable there.

## Verification

Lint, typecheck and the build passed locally, and the full test suite passed on CI for the release commit before tagging. The release workflow repeats the tests on CI before building the installer.
