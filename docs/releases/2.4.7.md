# HomeConnect 2.4.7

Customer moves keep their old-system account, Settings is English only, and revoked phones can be deleted. No PC database migrations, no phone app change. The cloud relay gets one new endpoint through its automatic deploy.

## Fixed

- **Moving a customer to another branch lost their old-system account number.** The next trial-balance import then matched them by name and asked for a decision. The account number now moves with the customer. It is kept with the destination branch's import of the same file, or with a placeholder record that keeps the original file name and date. An account number the destination branch already gives to a different customer is still left behind, and the move dialog says so before you confirm.

## Changed

- **Settings is English only.** Business details, Maintenance, Updates and Backups no longer show Arabic text.
- **Delete revoked phones.** In Settings → Phone cloud sync → Paired phones, a revoked phone now has **Delete**, and **Delete all revoked** removes them together after a confirmation. A phone with actions still waiting for the shop PC is kept, and the reason is shown, so no unsent work is lost. Deleting removes the phone and its finished actions and photos from the relay.

## Operator checklist

1. Install desktop **2.4.7**.
2. Wait for the relay's automatic deploy to finish on Render. Until then, Delete answers that the relay has not been updated yet; nothing is removed.
3. In Paired phones, click **Delete all revoked**, confirm, and check that only active phones remain.
4. Customers moved between branches before 2.4.7 already lost their account number: on the next import choose **Update** for them once.

## Verification

- New database tests: a moved customer keeps their account number with the original file date, the destination's import of the same file is reused, an account number taken in the destination is left behind, and the next import matches a moved customer by account number.
- New relay database test: a phone must be revoked and have nothing waiting before it is deleted, and its finished actions and photos go with it. Route and PC tests cover each refusal message, including a relay that is not updated yet.
- 568 tests in the customer, branch, sync and settings areas pass, plus the relay's 21 database tests.
