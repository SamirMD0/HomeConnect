# HomeConnect 2.4.11

Outstanding Debt on the dashboard now subtracts customer credit, so it equals the old system's balance. No PC database migrations, no phone app change, no relay change.

## Fixed

- **Outstanding Debt was higher than the old system by every customer credit.** 2.4.10 only listed deposits under the card. Outstanding is now open debts minus customer credit (credit balances carried over from the old system), the way the old system counts it.

## Changed

- **Outstanding Debt card:** under the value, "Debts · Customer credit · Prepaid orders held". The line wraps on narrow screens without splitting an amount.
- **Branches table:** Outstanding per branch is net of customer credit, with **Customer credit** and **Prepaid orders held** columns.
- **Prepaid orders held** (money paid ahead for goods not yet delivered) is shown but not subtracted. Mark an order **Delivered** on the Deposits page once the goods are handed over.
- Top debtors per customer and the Receivables page still show debts before credit.

## Operator checklist

1. Install desktop **2.4.11**.
2. On the dashboard, compare each branch's **Outstanding** with the old system's balance for that branch.
3. If a branch shows **Prepaid orders held** for goods already handed over, mark those orders **Delivered** on the Deposits page.

## Verification

- Checked in the app on a local copy of a recent shop backup: the card's value dropped by the customer credit, and each imported branch's Outstanding equalled the old system's balance to the cent.
- Tests: analytics totals net customer credit and keep prepaid orders apart (voided payments ignored); the card line keeps each amount whole.
- 293 dashboard and branch database tests and 70 dashboard unit tests pass; backend and frontend typechecks are clean.
