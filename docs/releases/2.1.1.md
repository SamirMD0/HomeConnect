# HomeConnect 2.1.1

## Fixes

- **Faster dashboard.** With several branches, the dashboard loads each record set once and splits it per branch. Before, it reloaded everything once per branch. Opening the dashboard now runs 26 database queries instead of 87, and the totals are unchanged.
- **Faster lists and reports.** New database indexes speed up branch-filtered payments, sales orders, debts, payment plans and the activity log. They also speed up lookups on customer credit applications, sales returns, supplier audits and customer import accounts.

## Migration notes

- `20261111120000_add_query_performance_indexes` runs on install. It only adds indexes (`CREATE INDEX IF NOT EXISTS`). No data changes and no manual steps.

## Operator checklist

- Open the dashboard with all branches selected and check the total and per-branch figures against 2.1.0.
- Open Payments, Sales orders and the activity log, then filter each by branch.

## Verification

The backend type check passes, and targeted dashboard tests pass, including a new two-branch breakdown test. On local data, the dashboard gives the same totals before and after the change, for all branches together and for each branch. The full CI suite passed in PR #4.
