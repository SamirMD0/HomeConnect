# HomeConnect 2.0.15

## Fixes

- Customer profile actions no longer ask for an admin or account password. This covers adding, editing, cancelling, and deleting customer records and financial obligations, payment corrections and voids, installment payment reallocations, prepaid purchase corrections and delivery reversals, credit-limit overrides, and customer branch transfers.
- The server accepts these actions without password confirmation. Existing sign-in, administrator permissions, correction reasons, financial validation, and audit history still apply.

## Migration notes

No database changes or manual migration steps.

## Operator checklist

- Open a customer profile and add, edit, and delete a disposable customer.
- Add and edit a debt and an installment plan; record a payment, reallocate an installment payment, and void a disposable payment.
- Edit and cancel a prepaid purchase and reverse a disposable prepaid delivery.
- Confirm a credit-limit override and a customer branch transfer no longer request a password.
- Confirm correction reasons and financial validation still apply.

## Verification

Targeted frontend, API, service, and validation tests pass locally, including checks for every affected dialog. Frontend and backend type checks pass; lint reports no errors. The release workflow runs the full database integration suite and migration rehearsal before building and verifying the Windows installer.
