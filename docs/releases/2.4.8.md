# HomeConnect 2.4.8

The customer trial-balance import now makes Barja and Jadra equal the old system after every import, not only the first one. No PC database migrations, no phone app change, no relay change.

## Fixed

- **Totals drifted after the first import.** Each later import held back some changes until you ticked them, so a gap stayed every day. The old system's balance now always wins: every account is set to the file's figure without a tick. When HomeConnect showed something different (for example a payment taken here that is not in the old system yet), the row says so, so you can enter it in the old system too.
- **A debt and a deposit stayed open for the same account.** The old system keeps one net balance per account. When the file no longer shows a credit, the deposit held here is now marked as used, and any credit still shown is kept as a deposit.
- **Customers who lost their account number needed a decision.** A customer with the same name and no account number is now given the file's account number automatically.
- **New customers landed in the IMPORT branch and had to be moved.** When you import into IMPORT, each new account now asks for Barja or Jadra and is created there with its account number.
- **"Not in this file" customers** are all ticked to settle by default.
- **Totals by branch:** the File columns now cover the whole file, so they can be compared with "Owed after import".

## Operator checklist

1. Install desktop **2.4.8**.
2. Import today's trial balance into IMPORT as usual.
3. Choose Barja or Jadra for any row marked **New account**.
4. Check rows with a yellow note that the old system wins, and enter any payment taken in HomeConnect in the old system too.
5. Confirm. Barja + Jadra "Owed after import" minus deposits should equal the file total without the Main branch's account.

## Verification

- Ran the import on a local copy of a recent shop backup with that day's file: customers without an account number were relinked, old differences were set to the file and a used deposit was closed. Barja + Jadra then equalled the file exactly, and a second import of the same file changed nothing.
- New database tests: a used credit, a partly used credit, relinking by account number, and a new account placed in its chosen branch. The four tests for the old tick-to-apply rules were rewritten.
- 165 customer tests pass; backend and frontend typechecks are clean.
