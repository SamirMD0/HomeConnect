# Home Connect 2.0.6

- Fix the Windows database update failure seen when upgrading 2.0.4 to 2.0.5. The Prisma schema engine is now shipped outside the application archive and launched from its physical path.
- Before installing future updates through HomeConnect, save and verify the working application and its database while the backend is stopped. If preparation fails, keep the current version running.
- Automatically restore the previous application and pre-update database if the new version fails during migration or first startup, then reopen HomeConnect. A separate watchdog also handles an update that cannot load its main process.
- Do not offer the same failed version again after automatic recovery. A newer patch remains eligible.
- Include the actual migration error in private diagnostics, with database credentials removed.

## Installing this recovery release

If 2.0.5 cannot open, close HomeConnect and run `HomeConnect-Setup-2.0.6.exe` directly on the business PC. Keep the existing pre-update backup. This patch corrects the packaged engine launch and retries the pending upgrade without resetting the database.

Automatic rollback applies to updates started from 2.0.6 or later. Older versions did not save an application rollback snapshot, so this mechanism cannot retroactively recover their failed installation.

## Verification

Release validation covers migration errors, failed preparation, duplicate install requests, snapshot/archive corruption, exact application restoration, atomic database restoration, failed-version suppression, the packaged Prisma engine, and an isolated upgrade/recovery rehearsal. Production data is not used for write tests.
