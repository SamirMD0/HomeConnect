# HomeConnect 2.0.8

Fix the in-app update failure that shows “Update not installed. Your current version is still available.” on 2.0.6 and 2.0.7. Electron treated the packaged `app.asar` file as a virtual directory during recovery snapshot creation, so copying the current installation failed before the new installer could launch.

Application snapshot copying, hashing, enumeration, and recovery now use Electron's physical filesystem for the archive. The existing database backup and recovery checks remain in place. This patch also retains the mobile sign-in fix from 2.0.7.

## Install directly once

The running 2.0.6/2.0.7 updater cannot acquire this fix through its broken preparation path. Close HomeConnect and run `HomeConnect-Setup-2.0.8.exe` directly, using the existing installation folder. Reopen the app, confirm version 2.0.8, then turn on Mobile Scanner in Scanner Hub and retry phone sign-in.

Keep the existing database configuration and backups. The installer does not require a database reset. If startup reports a migration failure, retain its diagnostics and follow the migration-failure runbook.
