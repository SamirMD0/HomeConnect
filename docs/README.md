# HomeConnect Documentation

This folder is organized by purpose so project context is easier to find.

## Project

- `project/PROJECT_ROADMAP.md` - product roadmap, architecture, and long-term release strategy.
- `project/FINANCIAL_FLOW_AUDIT.md` - financial flow audit and risk notes.

## Setup And Recovery

- `setup/ELECTRON_BUSINESS_PC_SETUP.md` - business PC installation and environment setup.
- `setup/BACKUP_RESTORE_RECOVERY_GUIDE.md` - database backup and restore recovery guide.
- `setup/MOBILE_SCANNER_SETUP.md` - scanning products from a phone on the shop Wi-Fi, and the network setup it needs.

## Plans

- `plans/LEDGER_UI_REDESIGN_PLAN.md` - ledger UI redesign checkpoints and decisions.

## Phase History

- `phases/phase-01/` through `phases/phase-12/` contain phase design, API, result, and checkpoint documents.
- `phases/phase-1-0-7/` documents the Product and Maintenance/Service foundation release.
- `phases/phase-1-0-8/` documents Supplier Management and the separate Supplier Ledger.
- Phase 11 is split into `backup-restore/` and `electron-desktop/` because both tracks were completed under the same phase number.

## Legacy Task Prompts

- `legacy-tasks/` contains the original early phase task prompt files kept for historical reference.
